## Root causes (5 Whys, for the defects that repeat or block a gate)

**D-01, machine-error gate cannot run off the Windows host.**
1. The validator fails on 12 of 12 targets because `Path(target["path"])` points at `<drive>:/<web-root>/...`.
2. The fixture stores a host path per target because it was written on that host.
3. The validator has no notion of a portfolio root, so a path is the only way to name a target.
4. The 29 October cycle replayed the check by hand in a temporary fixture and recorded the result in prose, so the fix lived in a report.
5. Process: a hand-run workaround was accepted as the evidence instead of being promoted into the validator, against Standard step 6 (Standardise).

**D-02, expired register fails and CI cannot catch expiry.**
1. The older register exits 1 because every record's `review_after` is 2026-10-03.
2. The 29 October cycle recorded dispositions in a newer register but left the older file as it was, which is correct for immutable history.
3. The validator has no way to read "superseded by" so an immutable file can never pass once its dates lapse.
4. CI never runs the validator on a real register (fixed fixture, fixed date), so no one saw the expiry as a failure.
5. Tooling: the currentness gate was specified in prose and wired to a fixture only.

**D-03 and D-04, premise check and single-claim lookups have no owner.**
1. The false-premise task was answered correctly only because the agent chose to check.
2. The critical-reasoning method frames the question but does not test presuppositions in it.
3. Three skills exclude single-claim lookups in "Do Not Use When" and none names a replacement.
4. The skill contract demands "Do Not Use When" sections but not a pointer to where the excluded work goes.
5. Skill: exclusions were written to keep orchestration light, and the lightweight path was never written.

**D-08, D-09, D-11 hygiene gaps that passed the scanners.**
1. Host paths survive in `CONTRIBUTING.md` and the authoring standard; a broken link survives in `skills/doc-standards.md`; 19 skills repeat headings.
2. The scanner covers `AGENTS.md`, `README.md` and `skills/**/*.md` only, matches sibling links by the prefix `chwezi-`, and never tests that a link target exists.
3. The contract validator checks duplicates only for the 13 required titles.
4. Each check was written against the defect that prompted it, in the shape of that defect.
5. Tooling: no check was derived from the class of defect (non-portable or unresolvable reference; repeated heading).
